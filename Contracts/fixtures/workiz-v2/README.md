# Workiz v2 public fixtures

Synthetic examples shaped from https://developer.workiz.com/v2/ (read 23 Oct 2026).
All IDs, people, addresses, phones and notes are invented. No credential or live response is included.
`jobs-page` and `jobs-last` cover scheduled, unscheduled, cancelled, completed and another technician's jobs.
The report field and client-note marker follow [the shared contract](../../fsm-workiz.md).
Phone tests and UI fixture transport consume these exact files. Attachment URLs must never be fetched.
The unzoned timestamps use the Workiz account timezone, selected in Settings.
