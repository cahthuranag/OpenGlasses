# Models

Invented models for the site-system fixture.

## NV80F060 (NV80-F060) gas furnace

Two-stage gas furnace with a communicating control board. Fault code F12 is a flame-sense fault.

## NV36HP2 (NV36-HP2) heat pump

Three-tonne communicating heat pump. Fault code E77 is a lost-communication fault.

## NV48HP2 (NV48-HP2) heat pump

Four-tonne communicating heat pump. Fault code E77 is a lost-communication fault.
